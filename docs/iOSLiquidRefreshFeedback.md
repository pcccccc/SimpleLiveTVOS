# iOS FullUI 黑色水滴刷新反馈

状态：当前为阶段性保存版本，用户尚未认可动效效果，后续需要继续调整形状和动画协调性。下述构建与功能验证不代表视觉设计已验收。

首页和收藏共用 `LiquidRefreshIndicator`。按住时仅随拉距改变形状；手指停止移动，水滴就保持当前形状，没有文字提示。达到系统刷新条件后，必须松手才开始请求与断开动画。

## 触发与生命周期

首页仍由 `refreshable` 判定刷新条件，收藏使用 `UIRefreshControl`。`PullRefreshReleaseGate` 在回调之后、请求及加载状态之前等待所属 scroll view 结束 tracking/dragging/pan。它不安装额外手势；只在等待松手时以可取消的异步任务观察原生状态。手势取消、视图离开窗口或任务取消时退出。收藏等待及请求共用一个任务避免重复触发，wrapper 拆卸时取消。

首页的 gate 绑定现有滚动探针所属 scroll view。首页 `refreshAll` 和收藏 `onRefreshChange(true)` 均在松手后才执行，之后递增 `refreshCycle`；即使极短请求的布尔开始／结束被 SwiftUI 合并，也不会漏掉动画。不修改共享网络或同步规则。

`LiquidRefreshPullState` 防止一次已刷新的下拉在回收后重新画出静止水滴。只有动画结束且拉距回到静止位置（不超过 1pt）才重新响应下拉；回收结束时读取最新拉距，不使用异步任务休眠前捕获的旧值。

## 形状与动画

- 最大圆滴直径 24pt，拉伸时仅轻微横向收窄；连接颈比早期版本短。
- 松手后前 0.18 秒先收颈，0.10–0.38 秒平滑下落。连接两端及腰部同时收窄，完全分离后不再绘制颈部。
- 短请求至少展示到 0.56 秒再回收，不延迟数据更新。
- 回收时长 0.48 秒。圆滴先上移，靠近顶部后连接，最后 35% 才缩小，避免长细线牵着小圆点的效果。
- 加载使用白色细弧。Canvas 仅绘制 120pt 局部区域，连接和圆滴分别填充，避免重叠路径镂空。
- 减弱动态效果使用固定圆滴与静态加载弧；后台暂停旋转，不拦截触摸，VoiceOver 提供刷新状态。

## 窗口适配

使用组件所属 UIView 的 window、safeAreaInsets 和坐标转换定位，不查询全局 key window。公开 UIKit 没有传感器缺口精确轮廓 API，安全区是保守推断，不是硬件边缘测量。

手机竖屏、组件铺满窗口且顶部安全区至少 44pt 时，在安全区上方 20pt 起笔，与常见灵动岛／刘海内重叠接合。无缺口屏、横屏、iPad 和窄栏使用独立水滴。布局、窗口和安全区改变后重新测量。所有改动只在 FullUI。
